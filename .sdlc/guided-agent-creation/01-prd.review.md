# Review: 01-prd.md (guided agent creation)
VERDICT: AMBER

Previous blockers: resolved. Test of an inactive agent is now criteria 24-27, verified against webcall/__main__.py:248-277 and cache_aside.py:201. The Easy test page is now criterion 29, plus criterion 28 for chat.

1. [minor] Config freshness after Accept, Undo and Activate is unspecified. get_agent and get_runtime_config are cache-aside, so a test or real call after "Put it to work" or Accept can run the stale prompt or the cached "inactive" state. The fix loop's value depends on the next test seeing the change. — criteria 24, 30, 40, 42 — fix: add a criterion that the first test session after Accept, Undo or Activate uses the new prompt and status, and that the test path reads the agent fresh, not through the cache.
2. [minor] Criterion 12 says roles other than voice with more than one config get a plain dropdown. Criterion 6 and the scope say the only editable controls are name, business name, business facts, language and the voice dropdown. The "exact set" test cannot satisfy both. — criteria 6 and 12 — fix: decide, either add AI-service and speech-recognition dropdowns to the criterion 6 set with plain labels, or make criterion 12 voice-only and say what happens when other roles have more than one config.
3. [minor] The test credential has no testable bounds. "Short fixed lifetime" has no value. "Valid for test sessions only" has no test that the credential is refused on a non-test entry point (a real call, telephony) or for a different agent's active runtime. Nothing says whether it is single-use or replayable within its lifetime. No rate limit is stated for minting, chat test turns or revise, each of which spends the tenant's LLM or STT/TTS. — criteria 24-26, 28 — fix: state the lifetime in seconds, add a criterion that a test credential presented to a non-test path is refused identically to no credential, state replay semantics, and cap mint and chat-turn rate per tenant.
4. [minor] Conversation must decide "test" from the credential, not from the client-supplied direction="test" in SessionOpen (webcall/__main__.py:276). Criterion 27 only covers a non-test call. A credential-less session claiming direction "test" for an inactive agent is covered only implicitly by 26. — criteria 26-27 — fix: add an explicit case, a SessionOpen with direction "test" and no valid credential for an inactive agent is refused identically to a non-existent agent.
5. [minor] The fix loop dead-ends on an Easy agent whose prompt was hand-edited (criterion 31) so it no longer has the three headings. Criteria 19 and 39 then reject every proposal with no message or recovery. — criteria 19, 31, 39 — fix: add a criterion that revise on a prompt failing criterion 15 returns a plain "this receptionist's instructions were edited by hand and can't be auto-fixed" message, and the UI does not offer the fix step.
