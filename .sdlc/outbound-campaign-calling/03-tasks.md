# Tasks: Outbound campaign calling (own SIP + CPaaS), crash-safe, with launch readiness

Conventions: `[P: Tn,…]` means file-disjoint from those tasks, so it can run in parallel with them (one message, per lesson 40); after any parallel batch run the full suite once on the merged tree (lesson 41). Billing runs through `NullBillingAdmission` (`billing_state='off'`) everywhere outside Phase 8. Tests named in "done when" run with the env in the repo `.env`; an import/connection error is BLOCKED-ENV, not a failure (lesson 50).

Plan-level flags: (a) `campaign_attempts` CHECK pins `max_call_s` to 30..7200 but `agents.max_call_duration_s` is unconstrained, so T14 clamps. (b) Phase 4 lands before the Phase 5 cutover so ESL removal never leaves native-DID campaigns without a path; if T1 fails, Phase 4 stops, and T27's `no_healthy_sip_node` block is the only Path A behaviour that ships. (c) Webhook-to-stream (T39) lands in the same phase as its consumer cutover, never earlier, or Path B outcomes are lost.
