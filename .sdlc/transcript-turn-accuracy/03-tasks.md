# Tasks: Transcript and turn-count accuracy

## Test environment
- Python command (repo root): `./venv/bin/python -m pytest -q -p no:cacheprovider -rfEs services/conversation/tests services/config/tests`. CI runs the whole tree as `python -m pytest -q -p no:cacheprovider -rfEs` (`.github/workflows/ci.yml:143`).
- Env: Python 3.11 venv from `requirements.txt`. Load `.env` first with `set -a; source .env; set +a`. `POSTGRES_DSN` must be non-blank and point at a reachable `voiceai` DB (CI: `postgresql://postgres:<password>@localhost:5432/voiceai`, ci.yml:45). Also `REDIS_URL=redis://localhost:6379/0`, `PGHOST=localhost`, `PGUSER=postgres`, `PGPASSWORD`, and a non-blank `JWT_SECRET`. `models/silero_vad.onnx` must exist (docs/setup.md:63-66).
- Services: Postgres 14 with pgvector (`brew services start postgresql@14`; CI image `pgvector/pgvector:0.8.0-pg14`), and Redis 7. Apply the schema with `psql voiceai -v ON_ERROR_STOP=1 -f database/schema.sql`, then knowledge, telephony, clinic, realestate and `rls.sql -v yuviz_app_password=...`, in the ci.yml:73-80 order. Re-apply `schema.sql` after T1 so the new columns exist. Ollama (`nomic-embed-text`, `qwen2.5:0.5b`) is only needed by suites outside this change.
- Admin UI (T19): `cd admin-ui && npm ci --no-audit --no-fund && npm run lint && npm run build && npm test`, on Node 22 with npm on PATH.
- Lesson 50/54: an import, fixture or connection error (blank DSN, no Postgres socket, `npm: command not found`) means BLOCKED-ENV. Diff the failures against base `main` before treating any of them as a regression.
